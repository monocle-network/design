# Design

This repository is the home of Monocle Network's visual assets, brand elements, and design guidelines.

## What lives here

- **Logo and visual assets** - SVGs, icons, and favicons
- **Social media assets** - profile icons, banners, and curated post graphics
- **Marketing assets** - banners, avatars, and presentation graphics
- **Brand guidelines** - the authority on colors, typography, and voice
- **UI mockups** - design concepts for the application and markets site

Some assets also live elsewhere: website and wiki design assets are kept in their respective repositories, and application assets (logo, loading screen, icon design) live in the [monocle](https://github.com/monocle-network/monocle) repository. Where assets are shared across projects, they may appear here too.

## Using the assets

Anyone is welcome to use these assets:

- **Community contributors** - posting on social media, setting up a new account, creating slides for a presentation, or making a press release
- **Third parties** - websites and publications referencing Monocle Network, for example a review wanting a logo

When using the assets, follow the brand guidelines.

## Contributing design work

Designers wanting to contribute can see what has been done, what the guidelines are, and what might be needed here.

To get started, read [Get Started](https://monoclenetwork.org/get-started) and then reach out to existing contributors in Monocle SimpleX spaces.
